# 📄 Invoicer - Premium Invoice Generator

A modern, high-end MERN stack application designed for professional invoicing. Built with a focus on premium aesthetics, liquid animations, and ease of use.

![Design Preview](https://via.placeholder.com/1200x600/4F46E5/FFFFFF?text=Premium+Invoicer+UI)

## ✨ Features

- **Live Animated Background**: Liquid ambient blobs for a dynamic, modern workspace feel.
- **Glassmorphism UI**: High-end translucent cards and components.
- **Invoice Builder**: Dynamic line-item management with real-time tax and discount calculations.
- **Premium PDF Export**: Perfect A4-aligned PDF downloads with custom logo support.
- **Client Ledger**: Manage your customer directory and billings efficiently.
- **Responsive Dashboard**: Quick overview of revenue, pending payments, and recent activity.
- **Multi-Currency Support**: Currently optimized for Indian Rupee (₹).
- **Demo Mode**: Built-in support to explore all features without immediate database configuration.

## 🚀 Tech Stack

- **Frontend**: React (Vite), Framer Motion, Lucide React, CSS (Custom Utility System)
- **Backend*: Node.js, Express
- **Database**: MongoDB (via Mongoose)
- **PDF Generation**: HTML2PDF.js

## 🛠️ Installation & Setup

### Prerequisites
- Node.js installed
- MongoDB (optional for demo mode, required for full persistence)

### Quick Start (Windows)
1. Clone the repository.
2. Double-click `START_PROJECT.bat` in the root folder.
   - This will install dependencies (first time only) and start both servers.

### Manual Setup

#### 1. Backend
```bash
cd server
npm install
npm start
```

#### 2. Frontend
```bash
cd client
npm install
npm run dev
```
